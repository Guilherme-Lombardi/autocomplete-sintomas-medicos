# 🩺 Autocomplete Inteligente no Apoio à Identificação de Sintomas Médicos

> **Análise de Viabilidade com Árvores de Decisão**

Artigo científico produzido como projeto acadêmico no Centro Universitário Braz Cubas, no curso de Ciência da Computação.

---

## 📋 Sobre o Projeto

Este trabalho investiga a viabilidade técnica e clínica do uso de **autocomplete baseado em árvores de decisão** para apoiar a identificação de sintomas médicos em ambientes clínicos. O estudo analisa benefícios, riscos e implicações éticas dessa tecnologia, discutindo seu papel como ferramenta de apoio ao diagnóstico — sem substituir a decisão clínica humana.

## 📌 Principais Conclusões

- O **autocomplete clínico** com árvores de decisão é uma ferramenta viável para apoiar o diagnóstico, oferecendo rapidez, padronização e interpretabilidade.
- Os melhores resultados ocorrem quando os modelos são treinados com **dados clínicos reais e curadoria médica rigorosa**.
- No contexto brasileiro, o **Prontuário Eletrônico do Paciente (PEP)** representa uma base sólida para implementação, desde que haja padronização terminológica e governança de dados.
- É indispensável **supervisão médica e validação contínua** para evitar vieses e garantir uso ético da IA.

---

## ⚠️ Desafios Identificados

- Interoperabilidade e integração com o PEP no Brasil
- Qualidade e balanceamento dos dados de treinamento
- Viés algorítmico e riscos de dependência excessiva dos sistemas
- Necessidade de auditorias, supervisão médica e transparência
